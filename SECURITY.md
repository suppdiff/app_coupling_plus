# Security Policy

## Supported versions

Security fixes are provided for the latest released version of App Coupling+.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting feature for this repository.

When reporting a vulnerability, include as much of the following as possible:

- a clear description of the issue
- affected App Coupling+ version
- reproduction steps
- potential impact
- relevant logs or screenshots
- any suggested mitigation or fix

Please allow reasonable time for investigation and a fix before public disclosure.
